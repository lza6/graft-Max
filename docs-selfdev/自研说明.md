# graft 源码（自研整合基地）

- 上游：https://github.com/nanonets/graft （npm: @nanonets/graft）
- 本副本：v0.28.0（main b9c2e23，与 npm latest 0.28.1 仅差补丁；`git pull` 即同步）
- TypeScript 源码在 `src/`（33 个模块），**已验证 `npm install && npm run build` 全绿**，
  自产 CLI `node dist/cli.js --version` → 0.28.0 可用。

## 目录速览（MCP 整合关注点）

| 路径 | 内容 |
|------|------|
| `src/mcp/` | **MCP server 本体**：server.ts / connector.ts / instructions.ts / kept-listing.ts |
| `src/tools.ts` + `tool-names.ts` | MCP 工具注册与命名（explore/context/affected 等） |
| `src/ai/` | LLM 摘要/合成（providers.ts 看模型接入方式） |
| `src/blast/` | blast-radius 影响半径分析 |
| `src/graph/` | tree-sitter 图谱（17 个 .scm query，构建后进 dist/graph/queries/） |
| `dist/viewer/` | 内置可视化 viewer（构建产物） |
| `test/` | 完整测试套件（含 workspace-sync-skills 等集成测试） |

## 常用命令

```powershell
cd D:\自研工具\graft
git pull origin main        # 同步上游（当前 0.28.0，npm latest 0.28.1）
npm install                 # 装依赖（25s，74 包）
npm run build               # 构建（tsc 0 错误 + viewer bundle + grammar wasm）
node dist/cli.js --version  # 验证自产二进制
npm test                    # 测试
```

## 与全局安装版的关系

- 全局 `graft` 命令（npm i -g @nanonets/graft@0.24.0 → MCP 在用）与源码副本**互不影响**
- 若想让 MCP 跑自产版：把 `claude mcp` 里 graft 的 command 换成
  `node D:\自研工具\graft\dist\cli.js mcp`（改动前先 `npm test` 验证）
