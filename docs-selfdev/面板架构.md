# 面板架构（graft-Max Dashboard）

> 面向维护者。回答三个问题：**数据从哪来**、**谁在轮询什么**、**安全边界在哪**。
> 最后更新：v0.28.0-max.10（N1/N8/N9/N11/N12/N14 落地后）。

## 1. 两个进程的两半

| 半边 | 文件 | 职责 |
|------|------|------|
| 服务端 | `src/mcp/dashboard.ts` | HTTP 路由、鉴权、Host 校验、安全头、数据聚合（读日志/会话/产物/探针） |
| 前端 | `panel/{index.html,main.ts,style.css}` → `dist/panel/` | 纯静态，esbuild 打包成 `app.js`（零运行时依赖） |
| 兼容回退 | `src/mcp/panel-legacy.ts` | max.9 的内联页面原样保留；`GRAFT_MAX_UI_LEGACY=1` 或 `dist/panel/` 缺失时使用，**一个 release 后删除** |

面板由 MCP server 旁路启动：`GRAFT_MAX_UI` 未设/为 `0` 就完全不启动（不占端口、不占内存）。

## 2. 路由表

| 路由 | 鉴权 | 数据源 | 缓存 | 说明 |
|------|------|--------|------|------|
| `GET /` | 否 | — | index.html 只读一次 | 新面板 HTML；带 `?token=` 时种 HttpOnly Cookie |
| `GET /app.js` `/style.css` | 否 | `dist/panel/` | `no-cache` | 静态资源；未构建 → 404 + 提示命令 |
| `GET /healthz` | 否 | — | — | **无鉴权、无数据**，专供容器 healthcheck |
| `GET /tail?n=N` | 是 | `~/.graft-max/mcp.log` | 无（倒序分块读） | `n` 默认 200、夹到 1..2000；**坏参数回退 200**（`?n=abc` 不再返回空 body） |
| `GET /sessions` | 是 | `sessions.json` → `liveSessions()` | 无 | 只过滤不写盘（P3-5） |
| `GET /stats` | 是 | 日志 + 会话 + 探针 + 构建状态 | toolStats 2s | 一个请求打包全部 KPI 数据 |
| `GET /storage` | 是 | 文件系统 | 30s（并发合并） | 顶层 `entries`（主 root，老形状）+ `roots`（全部仓库） |
| `GET /fresh` | 是 | `probeDrift()` + `stats.json` | 30s | N14 索引新鲜度 |
| `GET /reprobe` | 是 | `reprobeBackends()` | 无 | 显式重探三个联邦后端 + 叫醒 `tools/list` |
| `GET /favicon.ico` | 否 | 内联 SVG | 1 天 | 避免 404 污染控制台 |
| 其它 | — | — | — | `404 {"error":"not found"}` |

`/stats` 的字段契约（前端 `panel/main.ts` 的 `Stats` 接口与之逐字对应）：
`version, port, logPath, logBytes, rotated, sessionsFile, requests, roots, building[], toolStats{}, fedHealth[], fedCache{}`。

## 3. 轮询拓扑（实测数字，别凭印象改）

| 通道 | 间隔 | 说明 |
|------|------|------|
| 主轮询 `tick()` | 默认 2000ms，可调（最小 500） | 串行做 `/tail` → `/sessions` `/stats` `/tools` `/fed`；`Promise.all` 并发三张表 |
| 慢轮询 | 30s | `/storage`、`/fresh` 各自独立定时器，**不阻塞**主轮询（`/storage` 曾是 7.3s 的头号凶手） |
| 服务端 toolStats | 2s TTL | 解析最近 800 行日志 |
| 服务端 storage | 30s TTL | 目录遍历，并发请求共享一次 `storageInflight` |
| 服务端 fresh | 30s TTL | 每仓库一次指纹探针（~3ms/仓库） |
| 会话 `lastSeen` | 20s 节流 | 跨容器判活靠它 |
| 请求计数落盘 | 2s 节流 | `bumpRequests` 内存累加，`flushPendingBumps()` 兜底 |

暂停语义：`S.paused = true` 只停**主轮询**；「刷新」按钮、慢轮询之外的显式动作仍生效。

## 4. 安全边界（两种形态）

| 形态 | 绑定 | 令牌 | Host 白名单 |
|------|------|------|-------------|
| 宿主 | `127.0.0.1` | 默认关；`GRAFT_MAX_UI_TOKEN=<串>` 开，`=0` 显式关 | `127.0.0.1` `localhost` `::1` `[::1]` |
| 容器 | `0.0.0.0` | **强制**（未给则随机生成，完整 URL 只打到 stderr） | 上表 + 绑定地址 + `os.hostname()` |

- 令牌只走 stderr：`mcp.log` 正是 `/tail` 读的文件，写进去等于把钥匙挂在门上。
- 三种携带方式：`Authorization: Bearer`、`?token=`、Cookie `gm_ui`。
- 校验用 `crypto.timingSafeEqual`（先比长度，避免抛错）。
- 所有响应：`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`X-Frame-Options: DENY`、最小 CSP（面板是内联样式 + 外链 app.js，所以 `style-src 'unsafe-inline'`）。
- `/reprobe` 只跑各后端的 `--version` 探针，**绝不执行安装命令**（面板不是操作台）。

## 5. 多仓库（方案 A：一张面板看全部）

每个仓库的 MCP server 各起一个面板（端口被占自动 +1~+9），但它们读**同一份** `sessions.json`。
`knownRoots(primary)` = 主 root + 所有活跃会话的 `cwd`（去重、归一大小写与分隔符）。
于是任意一张面板都能列出全部仓库的会话、产物、新鲜度 —— 不需要把 root 变成数组参数，
也不去动联邦 gitnexus 的会话分桶（`federation.ts` 已按 cwd 分桶，见 P3-7）。

## 6. 前端工程纪律

1. **功能清单逐项勾销**（约束 C1）：任何前端重写先在 PR 里列旧功能清单，逐项在新实现里勾掉。max.9 弄丢"工具耗时卡片"就是没做这一步。
2. **DOM 都用 id 取，缺 id 直接抛**：`$()` 找不到元素会 throw，把"静默消失"变成"立刻炸给测试看"。
3. **所有交互用 addEventListener**，不用内联 `onclick`（可测、CSP 干净）。
4. **任何 API 失败都可见**：`api()` 把 401/403 翻成人话，`tick()` 三段各自 try/catch，失败只降级不静默。
5. 契约测试：`e2e/ui-interact.mjs`（26 条断言 + 零 `pageerror` + 零 console error）。改前端必须跑它。

## 7. 已知坑

| 坑 | 现象 | 处理 |
|----|------|------|
| Chromium fullPage 截图 + `position:sticky` | 截图里 header 跑到 KPI 下面（假象） | 截图前把 header 设 `position:static`（E2E 里已这么做） |
| `fetch` 不能伪造 `Host` | 断言 403 却拿到 200 | 用 `node:http` 原始请求测 Host 校验 |
| 端口 0 | 日志/令牌 URL 里出现端口 0 | `server.address().port` 才是真相（`/stats.port` 也用它） |
