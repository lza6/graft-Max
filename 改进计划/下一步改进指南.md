## 4. 任务详情（每条 = 一个可交付）

### M4 · 删除 panel-legacy
- **目标**：约束 C1（前端重写后一个 release 周期清退旧实现），避免两套 UI 分叉。
- **验收**：`grep -rn "panel-legacy" src/ test/` 无命中；`GRAFT_MAX_UI_LEGACY` 从 README/环境变量表移除；`ui-interact` 26/26 仍全绿。
- **回滚**：单文件 + 一个 import。

### M5 · 建图文件级进度
- **目标**：把"建图中 · N 秒"升级成"建图中 42/310 文件"。
- **改动范围**：`src/graph/build.ts`（每 25 个文件写一次进度，节流 500ms）、`src/graph/refresh.ts` 的 `buildingStatus()` 读它、`panel/main.ts` 显示。
- **不做什么**：不引入 IPC/事件流；进度仍然落在 `building.json`（子进程拥有，P3-9 不变）。
- **验收**：造一个 300 文件的仓库，建图过程中 `/stats.building[0].progress = {done,total}`；面板显示 `X/Y`；文件数小时不显示（避免抖动）。

### M8 · 日志脱敏（P1）
- **证据**：`src/mcp/devlog.ts` 的 `dlogBlock(title, body)` 把 `server.ts` 传入的
  `JSON.stringify(params.arguments)` 与工具 `text` 原文（clip 2000）写盘；
  而 `/tail` 把这文件原样吐给浏览器 → 任何进过入参的 token/私有片段都留在盘上。
- **改动范围**：`devlog.ts` 加 `redact()`（`sk-[A-Za-z0-9]{16,}`、`ghp_[A-Za-z0-9]{20,}`、
  `Bearer\s+\S+`、`(?i)(token|api[_-]?key|password)\s*[:=]\s*\S+` → 保留前 4 字符 + `***`）；
  `dlog`/`dlogBlock` 统一过它；**只脱敏不截断结构**（保持可 grep）。
- **验收**：单测喂含 4 类密钥的入参，落盘后原文不可见、结构仍在；`ui-interact` 仍 26/26。
- **风险**：误伤正常文本 → 用"保守模式"（只匹配明显密钥形态），并在 `失败模式手册.md` 记录。

### M11 · 真合并上游
- **步骤**：`git fetch upstream && git merge upstream/main` → README 冲突取 ours（我们整篇重写，
  上游只是换了徽章链接）→ 跑完整验证链 → 记录到 `上游同步SOP.md`。
- **验收**：`git rev-list --left-right --count HEAD...upstream/main` 变成 `N 0`；`npm test` 0 fail。

### M13 · 覆盖率门禁
- **现状**：`policy.md` §1 写了 80%/70% 门限，但**没有自动执行**（本轮未跑覆盖率工具）。

## 5. 风险与反模式（本轮新增）

1. **"新卡片忘了旧卡片"**——第二次教训的机会：任何面板改动先跑 `e2e/ui-interact.mjs`（26 条断言里有 6 条专门盯"旧功能还在不在"）。
2. **"截图当证据"**——Chromium fullPage + `position:sticky` 会生成假的错位图；用 `boundingBox()` + DOM 顺序才是证据。
3. **"`fetch` 能伪造 Host"**——不能（undici 禁止头）。测 Host 校验必须用 `node:http`。
4. **"单槽缓存配多仓库"**——多 root 时任何单键缓存都会退化成每次重算；缓存一律按 root 分桶。
5. **"断言钉死实现路径"**——`qmd` 有内嵌与 spawn 两条路，断言要接受两条（"其中一条真跑了"），否则 T2 之后永远失败。
6. **"以为测试跑全绿就是没问题"**——并行负载下上游有 flaky（`skills-session-start` 两个用例在 92 进程并发时偶发失败，独立跑 11/11）。判定回归必须单文件复现。

## 6. 横切约束（继承 v3.0 §9，全部仍有效）

C1 前端重写必须功能清单逐项勾销 · C2 用户全局文件一律 atomicWrite · C3 `tools/call` 热路径禁止无界同步 IO
· C4 后台进程必须有超时/并发上限/开关 · C5 同一能力多路径时输出契约由一处决定 · C6 非回环绑定必须
令牌+Host 校验+端口只发布到回环 · C7 每批收尾更新 `workflow_status.md`。

**本轮新增**：
| # | 约束 | 理由 |
|---|------|------|
| C8 | 缓存不得是单槽（多 root 场景必须分桶） | `/storage` 分桶前每个请求重算 N 次 |
| C9 | E2E 断言不得钉死"哪条实现路径"，只断言"行为与形状" | qmd 内嵌/spawn 双路径 |
| C10 | 面板截图前必须消除 sticky 伪影，或改用 boundingBox 证据 | 假错位图差点被当成布局 bug |
